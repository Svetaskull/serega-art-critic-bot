Учёт начался в v1.1; дни считаются по UTC. «—» означает неизвестную стоимость, а не нулевую. Сумма — расчёт по настроенным тарифам, не официальный счёт OpenAI; тарифы могут быть приблизительными. В v1.2 запись в кэш выделяется только по данным API либо при включённом допущении, что весь вход без cache reads был записан в кэш. Такое допущение может завышать стоимость. Если разделить запись и обычный вход нельзя, токены остаются «не классифицировано», а вызов — без расчёта. История v1.1 сохранена, но задним числом на категории кэша не разбивается. Учитываются успешные вызовы; тексты сообщений и промптов не сохраняются.
